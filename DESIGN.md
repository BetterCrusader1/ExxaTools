# ExxaTools — design

Один екран = одна робота. Застосунок має три вигляди: **Library**, **Game**,
**System**. Ніяких постійних панелей з логами й технічними шляхами на першому
плані — вони живуть там, де їх шукають.

## Палітра

| Токен | Hex | Роль |
| --- | --- | --- |
| `--ink` | `#0e1013` | фон вікна |
| `--rail` | `#13171c` | ліва навігація |
| `--surface` | `#181d24` | панелі |
| `--raised` | `#1f2630` | кнопки, активний пункт |
| `--line` | `#262f3a` | рамки |

| `--dim` | `#a9b4c3` | другорядний |
| `--faint` | `#7f8b9a` | підписи |

| `--mint` | `#6fd3a0` | успіх |

Золото тільки на головній дії та стані вибору. Решта — сірі поверхні.
Піднятий контраст другорядного тексту (AA на `--surface`).

## Типографіка

Montserrat (variable 400–800), локально з `web/fonts/`. Моно — тільки для
manifest id, ключів і логів. Шкала: 34 / 22 / 16 / 15 / 13 / 11.5.
Заголовки без uppercase-трекінгу, підписи — реченнєвий регістр.

Game view: hero 244px з артом гри та градієнтом зліва, назва 34px, метадані,
ряд дій (Install — єдина золота). Далі дві колонки: **Depots** і **Build**.

## Компоненти

- **Card (game)**: портрет 3:4, hover — підйом на 3px і тінь; підпис 13px/600.
- **Hero**: фон — `library_hero.jpg`, градієнт зліва 94% → 18%, знизу 92%.
- **Depots**: рядки-таблиця з шапкою `depot / size / key`; чекбокс 17px,
  розмір праворуч `tabular-nums`, ключ — моно-поле 168px, зелений коли є.
- **Build bar**: сегменти по частці розміру депо; вибрані — золоті.
  Під ним `N of M depots · 14.7 GiB`.
- **Кнопки**: 38px, radius 10; primary — золото з темним текстом; ghost —
  прозора; warn — золотий текст і рамка.
- **Chips**: 30px pill, активний стан — золота рамка й фон 12%.
- **Panels**: `--surface`, radius 18, padding 20, рамка 1px `--line-soft`.
- **Menu**: кнопка 38px з нашим знаком у правому верхньому куті, панель 250px.

## Рух

Один вхід на зміну вигляду (220ms, fade+6px). Hover/фокус — 140ms.
`prefers-reduced-motion` вимикає все.

## Доступність

Фокус видимий на всьому (2px золотий outline). Цілі ≥ 30px. Статус не
передається лише кольором — поруч текст. Контраст тексту ≥ 4.5:1.

## Адаптив

≥1080 — дві колонки. <900 — рейка стає верхнім баром. <620 — сітка 2 колонки,
ключ на всю ширину, hero 240px.
